# Evolve Hotels & Resorts — Web Portal

A luxury hospitality and rewards web application built with React, TypeScript, and Vite.

## Features

- **Luxury Property Discovery**: Curated properties across Kyoto, Manhattan, Houston Medical Center, and Little Rock.
- **Suite & Room Reservation**: Dynamic booking flow with real-time room availability, seasonal packages, and cancellation guarantees.
- **Guest & Member Scoping**:
  - Distinct reservation management with dedicated Guest Codes and registered Member IDs.
  - Multi-guest isolation and cross-tab `localStorage` synchronization.
  - Guest-to-Member account conversion with password persistence.
- **Evolve Rewards & Tier Status**: Member portal, points calculation, tier benefits, and reward nights catalog.
- **In-Stay Guest Experience**: In-room breakfast and dining folio ordering (exclusive for verified member stays).
- **Responsive & Modern UI**: Built with custom design tokens, serif luxury typography, and smooth micro-interactions.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Icons**: Lucide React
- **Styling**: Custom CSS Architecture (Modular design tokens & components)

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Type check and build bundle
npm run build

# Preview production build
npm run preview
```
